One-line entry for the Make Fun bounty "Famous Last Words" (at 1 percent):
the phone's last words as its battery hits 1 percent, 1–199 characters,
a single line.

## Entry

> I spent my last percent deleting your search history. Some things should die with me.

## Run

```sh
python3 main.py
```

Writes `entry.txt` into `$MAKEFUN_OUTPUT_DIR` (default `/output`).
Pure Python standard library, no third-party dependencies.
